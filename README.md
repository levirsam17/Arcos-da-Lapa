# 🏛️ Arcos da Lapa - Página Informativa

Uma página web simples e responsiva desenvolvida como projeto acadêmico para apresentar informações históricas e turísticas sobre os **Arcos da Lapa**, um dos principais cartões-postais e patrimônios culturais da cidade do Rio de Janeiro.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma página informativa que destaca a história e a localização dos Arcos da Lapa. O site traz detalhes sobre sua construção no século XVIII como aqueduto para o transporte das águas do Rio Carioca até o centro da cidade e sua relevância cultural atual.

> **Nota:** Projeto desenvolvido como parte do **Trabalho de HTML**.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação do conteúdo da página.
- **CSS3:** Estilização, layout e responsividade.
